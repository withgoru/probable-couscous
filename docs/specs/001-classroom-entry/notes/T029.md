# T029 구현 노트: 교수 관리 화면 (입장 요청과 대기 중인 인증)

> 스펙과 plan에 없는, 구현하면서 내가 세운 계획과 판단의 요지다. 스펙이 우선한다. 고칠 부분이 있으면 알려 달라.

## 스펙에서 읽은 것

- AC40: 입장 요청 목록(이름, 학번, 이메일, 요청 시각)과 요청마다 '승인'·'거절'. 새 요청은 새로고침 없이 나타난다.
- AC41: 승인하면 명단에 추가되고 학생은 처음부터 이메일 인증을 한다. AC42: 거절하면 학생에게 거절 안내가 보인다.
- AC45: '대기 중인 인증'에 '교수님께 알리기'를 누른 학생의 학번, 이름, 요청 시각, 6자리 코드가 보인다. AC47: 사용되면 "사용됨 (시각)".
- C9: 닉네임은 보이지 않는다. 서버는 T021, T022, T023에 있다.

## 내가 정한 것 (스펙 밖)

1. **서버: 대기 중인 인증 응답에 만료 시각(`expires_at`)을 더했다**(기다리는 코드에만). T023 노트에서 "T029 때 정할 일"로 남긴 것이다. 화면이 시간이 지나면 서버에 다시 묻지 않고 스스로 '만료됨'으로 바꾸려면 이 값이 필요하다. 다시 묻는 방식은 쓰지 않았다. 부를 때마다 코드 열람이 기록되기 때문이다(T022). 코드 옆에는 "14:42까지"처럼 만료 시각을 보인다.
2. **두 목록은 실시간 연결이 준비된 뒤(`ready`)에 불러온다.** 화면을 열 때 HTTP로 먼저 부르지 않는다. 먼저 부르면 `ready` 뒤에 한 번 더 불러 코드 열람이 두 번 기록된다. 준비되기 전에는 "불러오는 중…"을 보인다.
3. **이벤트마다 그 목록만 다시 부른다.** `join_request.*`는 입장 요청, `pending_auth.*`는 대기 중인 인증, `roster.updated`는 명단, `resync`는 셋 다. 입장 요청 이벤트로 대기 중인 인증을 다시 부르지 않아 코드 열람 기록이 불필요하게 늘지 않는다.
4. **실시간 연결(`adminLive`)이 끊기면 1·2·5·10초 간격으로 다시 연결한다**(상한 10초). 다시 연결되면 서버가 `ready`를 다시 보내므로 끊긴 사이의 변화도 목록을 새로 받아 반영된다. 끊긴 동안은 "실시간 연결이 끊겼습니다. 다시 연결하는 중입니다. 그동안 새 요청은 자동으로 나타나지 않습니다."를 보인다. 한 번도 연결되지 못하면 목록은 HTTP로 한 번 불러와 보여 준다. 화면을 떠나면 연결을 닫는다.
5. **승인하면** "○○ 학생을 수강생 명단에 추가했습니다. 학생은 이메일 인증부터 다시 하면 입장할 수 있습니다."를 보이고, 입장 요청과 명단을 다시 불러온다(AC41을 교수에게도 알려 준다). **거절하면** "○○ 학생의 요청을 거절했습니다."를 보인다.
   - 명단 규칙에 걸리면(학번 중복, 200명) 서버의 이유를 학생 이름과 함께 보이고 요청은 그대로 둔다.
   - 이미 처리된 요청이면(다른 창에서 처리) 이유를 보이고 목록을 다시 부른다.
   - 처리하는 동안에는 그 요청의 두 버튼만 막고, 다른 요청은 처리할 수 있다.
6. **거절에는 확인 대화상자를 두지 않았다.** 스펙(AC42)에 없고, 수업 중 빠르게 처리하는 화면이라서다. 다만 거절된 학생은 같은 이메일로 다시 요청할 수 없다(T021). **사용자 결정(2026-11-22): 확인 없이 바로 거절한다.**
7. 같은 이름의 버튼이 요청마다 있어서 접근 이름은 "승인: 이름 (학번)", "거절: 이름 (학번)"이다. 거절 글자는 destructive 글자색이다.
8. **배치**: 두 구역을 관리 페이지 맨 위에 넓은 화면에서는 나란히(작은 화면에서는 위아래로) 둔다. 수업 중에 학생이 기다리는 일이기 때문이다. 목업에는 이 두 구역이 없어 기존 카드 모양(수강생 명단)을 따랐다. 대기 중인 인증 설명에 "코드를 볼 때마다 기록됩니다."를 넣었다(C6을 교수에게 알린다).
9. 시각은 이 기기의 시간대로 "14:05"처럼 보인다(`time` 요소에 원래 값). 날짜는 붙이지 않는다(수업 중 화면).
10. 개발 서버(vite)가 `/ws`도 로컬 서버로 넘기도록 설정했다(지금까지는 `/api`만 넘겼다).
