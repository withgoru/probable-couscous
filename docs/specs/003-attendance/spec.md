# 출석 (코드, 수기 보정)

> 규칙: 이 문서에는 **관찰할 수 있는 동작**만 씁니다. 프레임워크, 테이블, API 경로, 라이브러리 이름은 plan.md에 씁니다.

## 목적

수업이 시작되면 교실 화면에 바뀌는 출석코드를 띄워 학생이 휴대폰으로 출석하고, 코드를 넣지 못한 학생은 수기 보정으로 처리해, 출석이 수업을 끊지 않게 한다.

## 용어

- **출석 받는 시간**: 학생이 출석코드로 출석할 수 있는 시간. 수업을 시작하면 열리고, 정해 둔 시간(5분·10분·15분, 기본 10분)이 지나거나 교수가 끝내면 닫힌다.
- **출석코드**: 출석 받는 동안 교실 화면에 보이는 숫자 6자리. 15초마다 바뀐다. 지금 코드와 바로 앞 코드를 받는다(입력하는 사이에 바뀌어도 된다).
- **출석 상태**: 회차마다 학생은 **출석** 또는 **결석**이다. 출석코드나 수기 보정으로 출석한 기록이 없으면 결석이다. 수기 보정으로 출석이 된 학생은 "출석 (수기)"로 구분해 보인다.
- **수기 보정**: 코드로 출석하지 못한 학생의 출석을 교수가 처리하는 것. 학생의 요청을 승인하거나, 교수가 출석 현황에서 직접 바꾼다.

## 시나리오

### S1. 수업 시작과 함께 출석 받기
- **누가·언제**: 교수가 수업을 시작할 때(002 S2).
- **무엇을 제공하나**: 자동으로 열리는 출석 받는 시간, 교수 수업 화면의 출석코드와 출석 수, 프로젝터 화면의 출석코드 카드, 끝내기·연장.
- **완료할 작업**: 슬라이드를 넘기며 수업을 시작하는 동안 학생들이 출석한다.

### S2. 학생 출석
- **누가·언제**: 입장한 학생이 출석 받는 동안 휴대폰으로.
- **무엇을 제공하나**: 입장 흐름 끝의 출석코드 단계(6자리 입력, 출석하기), 수기 출석 요청.
- **완료할 작업**: 교실 화면의 숫자를 넣어 출석하고 수업 화면으로 간다.

### S3. 수기 보정
- **누가·언제**: 코드를 넣지 못한 학생(휴대폰 문제, 늦게 옴)과 교수가, 수업 중이나 끝난 뒤에.
- **무엇을 제공하나**: 학생의 수기 출석 요청(사유), 교수의 승인·거절, 출석 현황에서 직접 바꾸기.
- **완료할 작업**: 출석이 실제와 맞게 정리된다.

### S4. 출석 현황과 내보내기
- **누가·언제**: 교수가 관리 페이지에서, 수업 뒤나 학기 말에.
- **무엇을 제공하나**: 회차별 출석 현황 표, 강좌 전체 CSV.
- **완료할 작업**: 학교 시스템에 옮길 출석부를 얻는다.

## 수용 기준

### 출석 받는 시간 (교수)

- [ ] AC1. 관리 페이지에 이 강좌의 **출석 받는 시간**(5분·10분·15분) 선택이 있고 처음 값은 10분이다. 바꾸면 "저장했습니다."가 보이고 다음에 시작하는 수업부터 쓰인다.
- [ ] AC2. 수업을 시작하면(002 AC9) 출석 받는 시간이 바로 열린다. 교수 수업 화면 위쪽에 출석코드 상자가 생긴다: 숫자 6자리, 다음 코드까지 남은 시간 막대, "N초 후 바뀜 · 출석 마감 M:SS".
- [ ] AC3. 출석코드는 15초마다 바뀐다. 교수 수업 화면, 프로젝터 화면, 같은 교수가 연 다른 수업 화면은 같은 순간에 같은 코드를 보인다.
- [ ] AC4. 출석코드 상자에 **5분 연장**과 **출석 마감**이 있다. 연장하면 마감 시각이 5분 늦춰진다. 마감은 "출석을 마감할까요? 이후에는 수기 보정으로만 출석할 수 있습니다."를 확인한 뒤 닫는다.
- [ ] AC5. 정해 둔 시간이 지나거나 마감하면 출석코드 상자가 사라지고 "출석 마감 · 출석 N / M"만 남는다. 마감한 뒤에는 **출석 다시 받기**가 있어, 누르면 정해 둔 시간만큼 다시 열린다(새 코드, 이미 출석한 학생은 그대로).
- [ ] AC6. 교수 수업 화면에 "출석 N / M"이 늘 보인다(M은 명단 인원). 학생이 출석하면 1초 안에 N이 바뀐다.
- [ ] AC7. 종료한 회차를 '이어서 수업하기'(002 AC40)로 다시 열면 출석 받는 시간은 저절로 열리지 않는다. 교수가 **출석 다시 받기**로 연다.

### 프로젝터 화면

- [ ] AC8. 출석 받는 동안 프로젝터 화면 오른쪽에 출석코드 카드가 보인다: 숫자 6자리(뒷줄에서 읽히는 크기), 다음 코드까지 남은 시간을 보이는 원형 표시, "15초마다 바뀝니다". 슬라이드는 카드에 가리지 않게 남은 폭에 맞춰진다.
- [ ] AC9. 출석이 마감되면 카드가 사라지고 슬라이드가 화면 가득으로 돌아간다. 다시 열면 카드가 다시 나온다.

### 학생 출석 (S2)

- [ ] AC10. 출석 받는 동안 입장한 학생은 입장 흐름 끝(채팅 이용 안내 다음)에 **출석코드** 단계를 본다: "교실 화면의 숫자 6자리를 입력하세요. 15초마다 바뀌니 보이는 숫자를 바로 입력하세요.", 6자리 입력 칸, **출석하기**, 수기 출석 요청 안내.
- [ ] AC11. 이미 수업 화면에 있던 학생도 출석 받는 시간이 열리면 새로 고치지 않아도 출석코드 단계로 바뀐다. 이미 이 회차에 출석한 학생은 바뀌지 않는다.
- [ ] AC12. 맞는 코드(지금 코드나 바로 앞 코드)를 넣으면 "출석했습니다."가 보이고 수업 화면으로 간다. 수업 화면의 수업 정보 줄에 "출석 완료" 배지가 보인다(아이콘과 글).
- [ ] AC13. 틀린 코드를 넣으면 "코드가 맞지 않습니다. 교실 화면의 숫자를 다시 확인해 주세요."가 보이고 입력 칸이 비워진다. 1분 안에 5번 틀리면 "잠시 뒤에 다시 입력해 주세요. (N초)"와 함께 남은 시간 동안 입력할 수 없다.
- [ ] AC14. 출석코드 단계에 있는 동안 출석이 마감되면 "출석 시간이 끝났습니다. 교수님께 수기 출석을 요청하세요."와 함께 수업 화면으로 가고, 수업 화면에 **수기 출석 요청** 버튼이 남는다.
- [ ] AC15. 출석 받는 시간이 아닐 때 입장하거나, 이미 출석한 학생은 출석코드 단계 없이 수업 화면(또는 대기 화면)으로 간다.
- [ ] AC16. 한 학생은 한 회차에 한 번만 출석한다. 이미 출석한 뒤 다른 기기로 코드를 다시 넣어도 상태는 바뀌지 않고 "이미 출석했습니다."가 보인다.

### 수기 보정 (S3)

- [ ] AC17. 출석코드 단계와(코드를 넣지 못했을 때) 수업 화면의 **수기 출석 요청**에서 학생은 사유(1~200자, 예: "휴대폰 배터리가 없었습니다")를 써서 보낼 수 있다. 보내면 "요청을 보냈습니다. 교수님이 확인하면 출석 처리됩니다."가 보이고, 같은 회차에 다시 보낼 수 없다. 요청은 회차가 진행 중인 동안만 보낼 수 있다.
- [ ] AC18. 교수 수업 화면에 "수기 출석 요청 N"이 보이고, 펼치면 요청마다 학번·이름·사유·시각과 **승인**·**거절**이 있다. 요청이 오면 1초 안에 수가 바뀐다.
- [ ] AC19. 승인하면 그 학생은 "출석 (수기)"가 되고 학생 화면에 "출석 완료" 배지가 생긴다. 거절하면 학생 화면에 "수기 출석 요청이 받아들여지지 않았습니다. 교수님께 직접 말씀해 주세요."가 보인다. 승인·거절은 되돌리지 않고, 바꾸려면 AC21로 직접 바꾼다.
- [ ] AC20. 관리 페이지의 출석 현황에도 그 회차의 대기 중인 요청이 보이고, 수업이 끝난 뒤에도 승인·거절할 수 있다.
- [ ] AC21. 교수는 출석 현황 표에서 학생마다 상태를 **출석**·**결석**으로 직접 바꿀 수 있다(요청이 없어도, 끝난 회차도). 결석에서 출석으로 바꾸면 "출석 (수기)"가 된다. 출석코드로 출석한 학생을 결석으로 바꿀 때는 "코드로 출석한 학생입니다. 결석으로 바꿀까요?"를 확인한다.

### 출석 현황과 내보내기 (S4)

- [ ] AC22. 관리 페이지에서 회차를 고르면 **출석 현황** 표가 보인다: 학번, 이름, 상태(출석/출석 (수기)/결석, 아이콘과 글), 출석 시각. 위에 "출석 N / M"이 있다. 상태로 거를 수 있다(전체·출석·결석).
- [ ] AC23. 한 번도 시작하지 않은 회차는 "아직 수업하지 않은 회차입니다."가 보이고 표가 없다.
- [ ] AC24. 관리 페이지에 **출석부 내려받기(CSV)**가 있다. 내려받은 파일은 한 줄에 학생 한 명(학번, 이름)이고, 한 번이라도 시작한 회차마다 한 칸(회차 이름, 값은 출석/결석)이며, 마지막 칸은 출석 횟수다. 엑셀에서 한글이 깨지지 않는다. 이메일은 넣지 않는다.
- [ ] AC25. 출석 현황과 CSV는 지금 명단의 학생만 담는다. 학기 중에 명단에 들어온 학생은 그 전 회차가 결석이다. 명단에서 빠진 학생의 기록은 지워지지 않지만 보이지 않는다.

### 권한과 접근성

- [ ] AC26. 출석 받는 시간 바꾸기·연장·마감·다시 받기, 승인·거절, 상태 바꾸기, 출석 현황, CSV는 그 강좌의 교수만 할 수 있다. 다른 교수나 학생이 시도하면 "이 강좌에 대한 권한이 없습니다."가 보인다.
- [ ] AC27. 학생은 자기 출석만 할 수 있고, 다른 학생의 출석 상태를 볼 수 없다. 명단에서 빠졌거나 로그인이 끊긴 학생(001)은 출석할 수 없다.
- [ ] AC28. 이 스펙의 모든 버튼과 입력은 높이 44px 이상이고, 키보드만으로 쓸 수 있으며, 초점 링이 보인다. 출석코드 입력 칸은 휴대폰에서 숫자 자판이 뜬다. 출석 완료·결석 같은 상태는 색과 함께 아이콘과 글로 보인다. 출석 결과("출석했습니다." 등)는 화면 낭독기에도 읽힌다.

## 오류와 예외 동작

- **학생 연결이 끊김**: 출석하기를 눌렀는데 저장되지 않았으면 "출석을 보내지 못했습니다. 연결을 확인하고 다시 눌러 주세요."가 보이고 입력한 숫자는 남는다. 그사이 코드가 바뀌었으면 바로 앞 코드까지는 받는다. 한 번 누른 출석은 두 번 기록되지 않는다.
- **교수 연결이 끊김**: 교수 수업 화면의 출석코드 상자에 "연결이 끊겼습니다. 다시 연결하는 중…"이 보이고 코드가 흐려진다(낡은 코드를 띄우지 않는다). 프로젝터는 서버 시각으로 계속 코드를 바꾸고, 학생은 계속 출석할 수 있다. 다시 연결되면 지금 코드와 출석 수로 돌아온다.
- **프로젝터가 끊김**: 출석코드 카드에 작은 끊김 표시가 보이고 코드가 흐려진다. 다시 연결되면 지금 코드로 돌아온다.
- **서버를 다시 시작함**: 출석 받는 시간(마감 시각), 출석 기록, 수기 요청과 그 처리는 남는다(C13). 코드는 서버를 다시 시작해도 같은 순간에 같은 값이다.
- **출석코드로 출석할 수 없을 때**(휴대폰이 없음, 화면이 안 보임, 입력이 계속 실패): 학생은 수기 출석 요청을 보내고, 교수는 승인하거나 출석 현황에서 직접 바꾼다(C12 대체 경로).
- **많은 학생이 한꺼번에 출석**: 학생 200명이 30초 안에 출석해도 모두 기록되고(유실 0), 각자 몇 초 안에 결과를 본다(plan에서 측정).

## 범위 밖

- 지각 상태(출석·결석만 둔다, 사용자 결정).
- 같은 기기로 여러 학생이 출석하는 것 막기(사용자 결정: 막지 않는다), 위치·와이파이 확인, QR 코드.
- 학생이 자기 출석 기록을 모아 보는 화면. 참여 점수 계산(006).
- 조교(관리자) 역할과 조교의 승인. 교수 보조 화면(태블릿).
- 설정(Settings) 화면의 "새 강좌 기본값". 출석 받는 시간은 강좌마다 관리 페이지에서 정한다.
- 한 회차에 출석을 여러 번 따로 받기(예: 수업 앞뒤 두 번). '출석 다시 받기'는 같은 출석을 다시 여는 것이다.

## constitution 영향

- C1: 출석은 행동 기록이라 참여 점수(006)에 쓸 수 있다. 채팅과 섞지 않는다.
- C2: 출석, 출석 시각, 수기 요청 사유는 학생이 만든 데이터라 공개 경로에서 읽을 수 없다.
- C5: 출석 받는 시간, 출석 기록, 수기 요청은 강좌·회차 단위로 구분한다.
- C6: 출석, 수기 요청, 승인·거절, 교수의 상태 바꾸기는 수정하지 않고 쌓는다. 출석 상태는 이 기록에서 계산한다.
- C7: 출석 기록은 멤버십을 가리키고 이메일을 넣지 않는다. 출석 현황과 CSV의 학번·이름은 교수가 올린 명단에서 가져온다.
- C8: 교수 전용 동작과 학생의 출석은 한 곳의 권한 판단을 거친다. AC26, AC27.
- C11: CSV에 이메일을 넣지 않는다. 보관 기간은 미결정 질문에 적었다.
- C12: 코드로 출석하지 못해도 수기 요청과 교수의 직접 바꾸기로 출석을 처리한다. 교수 연결이 끊겨도 학생은 출석할 수 있다.
- C13: 출석과 마감 시각은 저장소에 먼저 기록하고, 서버를 다시 시작해도 남는다.
- C14: 상태는 아이콘과 글로, 결과는 화면 낭독기로, 숫자 자판, 44px, 키보드.
- C16: 지각, 대리 출석 막기, 학생 기록 화면, 조교, 설정 화면은 범위 밖에 적었다.
