## 메모

### 2번 실험 (2026-11-24, 002 plan 위험 2)

환경: Apple M5, macOS, Node 24, Slidev `@slidev/cli` 53.1.0, Chromium(Playwright 1.65.1, 데스크톱과 iPhone 13 흉내). 샘플 4장(단계 0·3·0·1개, 노트 3개). 실험 코드는 버렸다.

| 가정 | 결과 |
|---|---|
| 바깥에서 위치 지시 | 통과. 슬라이드 안 `setup/root.ts`(`defineRootSetup`)가 `useNav().go(슬라이드, 단계, true)`를 부른다. `useNav`는 `@slidev/client`의 공개 API다. 지시 → 반영 28ms |
| 단계 수 알아내기 | 통과. `useNav().clicksTotal`이 현재 슬라이드의 단계 수를 준다(슬라이드 2 = 3, 슬라이드 4 = 1). 전체 수는 `total`. 모든 슬라이드의 단계 수를 한 번에 주지는 않으므로, 교수 화면은 현재 슬라이드에 들어갈 때 받은 값을 쓴다 |
| 자체 넘기기 끄기 | 통과. `router.beforeEach`가 다리가 지시한 이동 말고는 모두 거절한다. →·Space·↓·PageDown, 주소 해시 직접 바꾸기 모두 그대로였다. 터치 스와이프도 그대로였지만 스와이프가 실제로 일어났는지는 따로 확인하지 못했다(같은 라우터를 거치므로 막힐 것으로 본다. 실기기 확인 목록에 넣는다) |
| 고정 기준 경로 바꾸기 | 통과. `--base /__deck__/`로 빌드하면 그 문자열이 `index.html`과 JS 4개, `404.html`, `_redirects`에 들어간다. `.html/.js/.css/.json`에서 바꾼 뒤 `/decks/1/`에서 정상 동작. `routerMode: hash`라 대체 경로가 필요 없다(`404.html`, `_redirects`는 쓰지 않음) |
| 노트 추출 | 통과. `@slidev/parser/fs`의 `load()`가 슬라이드별 `title`, `note`를 준다. `--without-notes` 빌드 결과에는 노트 글이 없다 |

추가로 알게 된 것
- **외부 요청**: 기본 빌드는 Google Fonts와 jsDelivr(파비콘)를 부른다. 학생 IP가 외부로 나가고 교실 인터넷이 없으면 늦어진다. 머리말에 `fonts: { provider: none }`, `favicon: false`를 두면 외부 요청이 없다. 템플릿에 넣는다.
- **슬라이드는 따로 나뉘어 담긴다**: 슬라이드마다 JS 파일이 따로 생긴다(`md-*.js`). 화면에서 막기로 결정했으므로 지금은 쓰지 않지만, 나중에 파일 단위로 숨길 때 실마리가 된다.
- **크기**: 이 샘플은 788KB(그림 없음). 그림이 든 실제 수업 묶음의 크기는 002 plan 위험 4에서 잰다.
- **슬라이드 수 맞추기**: 노트 추출은 원본 파일 기준이고 화면은 빌드 기준이다. `src:` 가져오기나 숨긴 슬라이드가 있으면 둘이 다를 수 있다. 교수 화면이 처음 열 때 `total`과 노트 파일의 슬라이드 수를 비교해 다르면 알린다.
