# T015 구현 노트: 관리 페이지 회차 선택과 회차 관리 화면

> 스펙과 plan에 없는, 구현하면서 내가 세운 계획과 판단의 요지다. 스펙이 우선한다. 고칠 부분이 있으면 알려 달라.

## 스펙과 plan에서 읽은 것

- AC1: 관리 페이지 위쪽에 회차 선택. 회차가 없으면 "아직 회차가 없습니다. 회차를 만들어 수업을 준비하세요."와 **회차 만들기**.
- AC2: 이름 1~40자, '예정'으로 목록 끝에 생기고 선택된다. 이름이 비면 만들기 버튼이 흐려진다.
- AC3: 목록에 이름과 상태(예정/진행 중/종료)가 글로. 진행 중은 아이콘과 글로(색만으로 구분하지 않음).
- AC4: 이름은 언제든 바꾼다. 삭제는 한 번도 시작하지 않은 예정 회차에만. 확인 문구 "{회차 이름} 회차를 삭제할까요? 올린 슬라이드도 함께 지워집니다.".
- 목업(Admin): 제목 "관리 페이지", 오른쪽에 회차 선택.

## 내가 정한 것 (스펙 밖)

1. **회차 선택은 메뉴(라디오 항목)다.** 기본 `<select>`는 항목 안에 아이콘을 넣을 수 없어 AC3을 지킬 수 없다. 그래서 bits-ui `DropdownMenu`의 라디오 묶음을 썼다. 키보드로 열고 고를 수 있고, 고른 항목은 `aria-checked`로 읽힌다.
   - 버튼에는 고른 회차의 이름과 상태가 보인다. 읽는 이름은 "회차 선택: {이름} {상태}"이다(보이는 글을 포함한다).
   - 진행 중 아이콘(`presentation`)과 고른 표시(`check`)는 서로 다른 아이콘이다.
   - 메뉴 맨 아래에 **새 회차 만들기**가 있다.
2. **처음 선택되는 회차**: 진행 중인 회차 → 없으면 아직 시작하지 않은 첫 예정 회차 → 없으면 마지막 회차. 교수가 고르면 그 회차를 유지한다. 지운 회차를 골라 두었으면 다시 기본값으로 돌아간다. 고른 회차는 주소에 남기지 않는다(새로 고치면 기본값).
3. **만들기와 이름 바꾸기는 같은 폼**이다. 회차 선택 아래에 펼쳐진다. 001 강좌 만들기와 같은 규칙을 따른다.
   - 비었을 때 흐림과 이유 문구 "회차 이름을 입력해 주세요."(입력 칸과 연결)
   - 40자 입력 제한, 앞뒤 공백 빼고 보내기
   - 서버 안내는 그대로 보이고, 연결 실패는 할 일과 함께 보인다
4. **삭제 버튼은 서버의 `can_delete`로 정한다.** 한 번도 시작하지 않은 회차일 때만 참이고, 그런 회차는 언제나 '예정'이다.
5. **목록은 페이지 `load`가 불러오고 `app:sessions`로 다시 불러온다**(001의 `app:roster`와 같은 방식).
6. **고친 것 하나**: T031에서 만든 '수업 화면으로' 버튼과 이번 버튼에 `btn-primary`를 썼는데, 테마(`theme.css`)에는 `btn-default`만 있다. 그래서 색이 입혀지지 않았다. 모두 `btn-default`로 바꿨다. 지우기 버튼은 001과 같은 `btn btn-outline text-destructive-strong`이다.
