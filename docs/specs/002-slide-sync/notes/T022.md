# T022 구현 노트: 프로젝터 화면

> 스펙과 plan에 없는, 구현하면서 내가 세운 계획과 판단의 요지다. 스펙이 우선한다. 고칠 부분이 있으면 알려 달라.

## 스펙과 plan에서 읽은 것

- AC19: '프로젝터 화면 열기' → 새 창. 슬라이드만 16:9 맞춤으로 화면 가득. 노트, 다음 슬라이드, 버튼은 없다. **전체 화면** 버튼이나 F 키로 전체 화면.
- AC20: 교수의 위치(슬라이드와 단계)를 그대로 따라오고 직접 넘길 수 없다.
- AC21: 슬라이드 왼쪽 위에는 아무것도 얹지 않는다. 연결 상태 표시는 오른쪽 아래 구석에 작게, 끊겼을 때만.
- AC22: 교수 계정으로만 열린다. 로그인하지 않았으면 교수 로그인 화면으로 간다.
- 오류 동작 "프로젝터 연결이 끊김": 슬라이드는 그대로, 오른쪽 아래에 작은 표시만. 다시 연결되면 교수의 현재 위치로 간다.
- plan: 프로젝터 오른쪽 사이드바 자리는 슬롯만 두고 비워 둔다(003 출석코드, 004 채팅이 채운다).

## 내가 정한 것 (스펙 밖)

1. **창 열기**: 교수 수업 화면의 버튼이 `/courses/{강좌}/projector`를 이름 붙은 창으로 연다(T018). 다시 누르면 같은 창을 쓴다.
2. **화면**
   - 검은 면(어두운 면 색) 위에 16:9 상자를 화면에 맞춰 놓는다. 남는 곳은 띠가 된다.
   - 슬라이드 iframe은 초점과 클릭을 받지 않는다(`tabindex=-1`, `pointer-events-none`). 그래서 F 키가 늘 이 화면에 오고, 슬라이드 안에서 넘기는 일도 생기지 않는다.
   - 넘기려 한 방향(`deck:intent`)은 받지 않는다. 서버도 프로젝터 연결의 넘기기를 거절한다(T009).
3. **"버튼은 보이지 않는다"(AC19)**: 교수용 조작(이전·다음 등)이 없다는 뜻으로 읽었다. 스펙이 요구하는 **전체 화면** 버튼만 오른쪽 아래 구석에 둔다.
   - 전체 화면이면 숨는다.
   - 마우스를 3초 움직이지 않으면 숨는다. 브라우저의 F11이나 창 최대화로 전체 화면을 켜면 이 화면은 알 수 없어서, 숨기지 않으면 버튼이 학생 모두가 보는 슬라이드 구석에 계속 남는다(리뷰에서 찾음).
   - 마우스를 움직이거나 키를 누르면 다시 보이고, 초점이 있으면 숨지 않는다.
4. **F 키**: F(대소문자)만 전체 화면을 켜고 끈다. Ctrl/Cmd/Alt+F(찾기)와 길게 눌러 반복되는 키는 받지 않는다. 전체 화면을 켤 수 없으면 구석에 "전체 화면을 켤 수 없습니다. 브라우저의 전체 화면(F11)을 써 주세요."를 보인다.
5. **연결 끊김 표시**: 오른쪽 아래 구석의 늘 있는 알림 자리(`role="status"`)에 "연결 끊김"을 작게 보인다. 평소에는 비어 있다.
6. **제목**: 화면 낭독기용 제목(h1)은 보이지 않게 둔다(슬라이드 위에 얹지 않는다). 슬라이드가 없는 수업은 회차 이름을 크게 보인다.
7. **수업이 없거나 끝났을 때**: 프로젝터는 진행 중인 회차를 따라간다. 그래서 보던 수업이 끝나면 회차가 사라지는데, 이때 "수업이 끝났습니다."를 보인다(리뷰에서 찾음). 처음부터 수업이 없었으면 "진행 중인 수업이 없습니다."다. 나중에 다른 수업이 시작되면 새로 고치지 않아도 그 수업으로 넘어간다.
8. **불러오기 실패**는 이유와 "잠시 뒤 자동으로 다시 불러옵니다."를 보인다(리뷰에서 찾음).
9. **오른쪽 사이드바 자리**: 지금은 슬라이드가 전체 폭을 쓴다. 목업의 "채팅 끄기" 배치와 같다. 사이드바는 003·004에서 같은 화면에 열을 더해 채운다. 비어 있는 400px 열을 미리 두면 학생이 보는 슬라이드만 작아져서 두지 않았다.
10. **로그인**: 레이아웃의 로그인 가드가 이미 `/courses/...`를 보호한다. 테스트에 프로젝터와 교수 수업 화면 주소를 더해 확인했다.
