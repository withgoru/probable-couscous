## 내가 정한 것 (스펙 밖)

1. **학생을 알아보는 자리(`app/class_access.py`).** 기존 `authz.get_actor`는 강좌를 모른 채 교수만 알아본다. 학생의 기기 로그인은 계정 단위라 강좌를 알아야 학생인지 정해진다. 그래서 강좌를 먼저 불러온 뒤 행위자를 정하는 `guard_class`를 두었다. 판단은 여전히 `authz.decide` 한 곳에서 한다(C8, 라우트 전수 검사도 이 guard를 알아본다).
   - 입장한 학생 = 유효한 기기 로그인 + 그 강좌 살아 있는 명단에 이메일 + 로그인 끊기 뒤에 만든 로그인 + 그 로그인으로 '확인하고 입장'까지 마침. 001 `join.py`에 있던 같은 확인(`_fresh_login`)을 이 모듈로 옮겨 둘이 같은 규칙을 쓴다(동작은 같고, 001 테스트가 그대로 통과).
   - 다른 강좌에만 입장한 학생은 403 "이 강좌에 입장한 학생만 볼 수 있습니다."(001의 `not_member` 문구), 로그인 없는 사람은 401.
   - 학생 화면이 쓸 수업 상태 API(T008)와 수업 WebSocket(T009)도 이 자리를 쓴다.
2. **묶음 파일은 경로 `/decks/{묶음}/…` 하나.** 지운 묶음(바꾸기로 밀려난 것 포함)·없는 묶음은 404 "찾을 수 없는 슬라이드입니다.". 기록은 있는데 파일이 없으면 410 "슬라이드를 열 수 없습니다. 묶음을 다시 올려 주세요.".
3. **노트 파일(`classroom-deck.json`)은 교수에게도 정적 경로로는 내주지 않는다.** 노트는 `GET /api/classrooms/{id}/sessions/{s}/deck/notes`로만 나간다(교수 전용, `Cache-Control: no-store`). 경로 하나에서 사람마다 다르게 주는 것보다 단순하고 실수가 적다.
4. **캐시는 `private`.** 로그인한 사람만 받는 파일이라 공유 캐시(프록시)에 두지 않는다. 해시 파일(`이름-8자 이상.확장자`)은 `private, max-age=31536000, immutable`, 나머지는 `private, no-cache`. 모든 응답에 `frame-ancestors 'self'`와 `nosniff`.
5. **폴더 밖 경로는 두 겹으로 막는다.** `..`·`.`·역슬래시가 든 경로를 거절하고, 실제 파일 위치가 묶음 폴더 안인지 다시 본다(폴더에 링크가 생겨도 밖의 파일을 내주지 않는다).
6. **회차 목록과 올리기 응답의 묶음에 `available`을 더했다.** 파일이 없으면 거짓이다. 교수 화면(T016, T018)이 "열 수 없음"을 보이는 데 쓴다.
