# T025 구현 노트: 학생 수업 화면 — 자료 탭

> 스펙과 plan에 없는, 구현하면서 내가 세운 계획과 판단의 요지다. 스펙이 우선한다. 고칠 부분이 있으면 알려 달라.

## 스펙과 plan에서 읽은 것

- AC33: 보낸 항목은 1초 안에 '자료' 맨 위에 나타난다. 화면 아래에 "교수님이 자료를 보냈습니다."가 몇 초 보이고 화면 낭독기에도 읽힌다. '자료' 탭에 읽지 않은 수가 보인다.
- AC34: 글 항목에는 **복사** 버튼. 누르면 글 전체가 복사되고 "복사했습니다.". 링크는 새 탭으로 열린다.
- AC35: 거둔 항목은 1초 안에 학생 화면에서 사라진다.

## 내가 정한 것 (스펙 밖)

1. **`MaterialsPanel` 컴포넌트**로 뗐다. 학생 수업 화면은 회차마다 새로 띄운다. 새 회차에 이미 있던 항목을 '새 자료'로 세지 않게 하려는 것이다.
2. **알림**
   - 새 항목이 오면 "교수님이 자료를 보냈습니다."를 화면 아래에 4초 보인다. 늘 있는 알림 자리(`role="status"`, `aria-live="polite"`)라 화면 낭독기가 읽는다.
   - 화면을 처음 열 때 이미 있던 항목으로는 알리지 않는다. 끊긴 동안 와서 다시 붙어 나타난 항목은 알린다.
   - 몇 초 안에 여러 개가 오면 한 번만 알린다(문구가 같다).
3. **읽지 않은 수**: 학생이 이 화면을 보고 있고(다른 앱·탭이 아님) 자료 구역이 화면에 들어와 있으면 읽은 것이다.
   - 세로 휴대폰에서는 자료 구역이 늘 화면에 걸려 있어 수업 중에는 수가 거의 생기지 않는다. 수가 쓸모 있는 때는 학생이 다른 앱에 갔다 돌아올 때다.
   - 다른 앱에 있는 동안 온 항목은 셌다가, 돌아와 자료가 보이면 비운다(리뷰에서 찾음).
   - 화면에 보이는지 알 수 없는 브라우저(`IntersectionObserver` 없음)에서는 보인다고 봐서 수가 쌓여 남지 않는다.
   - 거둔 항목은 수에서도 빠진다.
   - 수는 제목 안에 있어서("자료 새 자료 2") 제목으로 옮겨 다닐 때 함께 읽힌다.
4. **복사**
   - 쓴 그대로(줄바꿈, 들여쓰기) 복사한다. "복사했습니다."는 그 항목 안에 3초 보인다. 화면 낭독기용 알림 자리는 목록 전체에 하나다.
   - 복사하지 못하면(http처럼 클립보드를 못 쓰는 곳, 거부) 거짓으로 알리지 않고 "복사하지 못했습니다. 글을 선택해 직접 복사해 주세요."를 남긴다. 사라지지 않는다.
   - 버튼의 읽는 이름은 "복사: {글 앞 30자}"다(보이는 "복사"로 시작).
5. **링크**: 새 탭(`rel="noopener noreferrer"`)으로 열리고, 화면 낭독기에는 "(새 탭에서 열림)"을 덧붙인다. 링크만 있는 항목에는 복사 버튼이 없다.
6. **도착 알림이 가리지 않게** 자료 구역 아래에 여백을 두었다. 알림은 누름이 통과한다(`pointer-events-none`).
7. **"탭"**: 스펙은 "'자료' 탭"이라고 하지만 지금은 탭이 하나뿐이라 제목이 붙은 구역이다. 채팅(004)이 오면 화면 설명(screens.md)의 "채팅 / 자료" 밑줄 탭이 된다. 그때 읽지 않은 수는 탭 이름에 붙는다(다른 탭을 보는 동안 온 자료).

## 확인한 것

- 테스트를 썼다.
  - `MaterialsPanel.test.ts` 17개, 학생 수업 화면 1개

  - 변형 검사: 18개 중 16개를 잡았다. 남은 2개(회차가 바뀔 때 새로 띄우기, 복사 실패 안내 유지)는 테스트를 더해 잡았다.
