# T019 구현 노트: 교수 수업 화면 — 동기화 현황과 연결 끊김

> 스펙과 plan에 없는, 구현하면서 내가 세운 계획과 판단의 요지다. 스펙이 우선한다. 고칠 부분이 있으면 알려 달라.

## 스펙과 plan에서 읽은 것

- AC15: 슬라이드 아래에 "따라가는 중 N명 · 직접 넘겨 보는 중 M명". 학생이 들어오거나 전환하면 바뀐다. 누가 어느 쪽인지는 보이지 않는다(C7).
- 오류 동작 "교수 연결이 끊김": "연결이 끊겼습니다. 다시 연결하는 중…". 이전·다음과 보내기가 흐려진다(눌렀는데 반영되지 않은 척하지 않는다). 다시 연결되면 저장된 위치에서 이어진다.
- 목업 Main: 슬라이드 → 이전/다음 → 동기화 상태 → 다음 슬라이드 카드 → 발표자 노트.

## 내가 정한 것 (스펙 밖)

1. **현황 줄의 자리**: 이전·다음 바로 아래, 다음 슬라이드 카드 위(목업 순서). 슬라이드가 없거나 열리지 않아도 보인다.
   - 현황을 아직 받지 못했으면 숫자를 지어내지 않고 줄을 숨긴다.
   - 현황 줄은 화면 낭독기에 바뀔 때마다 읽히지 않는다. 학생 40~200명이 들어오고 바꿀 때마다 읽으면 수업을 방해한다. C14가 요구하는 것은 도착 알림이다.
2. **끊김 안내**
   - 스펙 문구 그대로 보이고, "다시 연결되면 저장된 위치에서 이어집니다. 학생과 프로젝터는 마지막 슬라이드에 머뭅니다."를 덧붙인다.
   - 안내 자리(`role="status"`)는 늘 있고 글만 들어간다. 글과 함께 새로 생기는 알림 자리는 VoiceOver 등이 읽지 않는 경우가 있다(리뷰에서 찾음).
3. **끊긴 동안**
   - 이전·다음은 `aria-disabled`로 흐리게 하고 끊김 안내와 연결한다. 버튼, 키보드, 슬라이드 안의 넘기기 모두 받지 않는다.
   - 마지막 슬라이드는 그대로 둔다.
   - 현황과 위쪽 줄의 접속 수는 마지막으로 받은 숫자에 "(연결이 끊기기 전)"을 붙인다. 지금 숫자인 척하지 않는다(리뷰에서 찾음).
   - 넘기는 중에 끊겨 실패하면 오류를 따로 남기지 않는다. 끊김 안내가 대신하므로, 다시 붙은 뒤에 오래된 오류가 남지 않는다(리뷰에서 찾음).
4. **다시 붙으면**: `classLive`가 상태를 통째로 다시 받는다(T014). 서버는 교수 연결에 `ready` 직후 현황을 다시 보낸다(T009). 그래서 위치와 숫자가 함께 맞춰진다.
5. **'끝남'(gone) 상태**는 학생을 내보낼 때만 생겨서 교수 화면에서는 다루지 않았다.

## 다음 작업으로 넘기는 것
