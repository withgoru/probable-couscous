# T035 구현 노트: 학생 수업 화면 — 공개 묶음은 끝까지, 비공개는 따라가기만

- AC27: 비공개 묶음이면 따라가기만 한다. 이전·다음·교수 화면으로가 없고, 밀기·←·→도 움직이지 않는다. 따라가기 줄에 "교수 화면 따라가는 중 · 교수님이 슬라이드를 공개하면 직접 넘겨 볼 수 있습니다.".

- tasks: 애드온과 다리에서 `deck:limit`을 빼고 테스트용 묶음을 다시 빌드한다. `limit`을 쓰던 코드가 남지 않는다.

## 내가 정한 것 (스펙 밖)

1. **넘겨 볼 수 있는 때**: 공개 묶음이고 열 수 있을 때다. 열 수 없는 공개 묶음도 버튼이 없다.
2. **넘겨 볼 수 없게 되면**(비공개로 바뀜, 또는 묶음을 열 수 없게 됨) 직접 넘겨 보던 학생은 교수 화면으로 돌아간다. 교수 화면의 현황도 '따라가는 중'으로 바뀐다.
   - "비공개로 바꿨습니다" 안내는 비공개로 바뀐 때만 보인다. 열 수 없게 된 때는 슬라이드 자리의 "열 수 없습니다" 안내가 이미 있다.
   - 이 안내는 따라가기 줄 아래에 남아 있다가, 다시 공개되거나 다음 수업이 시작되면 지운다.
   - 따라가던 학생에게는 따로 알리지 않는다. 따라가기 줄의 글이 바뀌고, 그 줄은 늘 있는 알림 자리라 읽힌다.
3. **화면 낭독기 알림**
   - 안내는 학생 수업 화면에 늘 있는 알림 자리로 읽힌다.
   - 같은 글이 다시 오면(비공개 → 공개 → 비공개) 화면 낭독기가 읽지 않아서, 비웠다가 다시 쓰게 했다(리뷰에서 찾음). "수업이 시작되었습니다", "수업이 끝났습니다"도 같은 방식으로 바꿨다.
4. **초점**
   - 비공개로 바뀌어 넘기기 버튼이 사라질 때 초점이 거기 있었으면 수업 제목으로 옮긴다.
   - 다른 곳(글 입력 칸 등)에 있으면 빼앗지 않는다. 두 겹으로 막았다(리뷰에서 찾음).
     - 수업이 끝나면 "버튼에 있었다"는 기억을 지운다. 화면이 사라질 때는 focusout이 오지 않아서다.
     - 실제로 초점을 잃었을 때만 옮긴다.
   - 변형 검사에서는 둘 중 하나만 빼면 다른 하나가 막아 테스트가 통과한다. 둘 다 빼면 잡는다.
5. **애드온**: `deck:limit`을 뺐다.
   - 지시한 이동만 통과시키는 처리는 그대로다. 따라가는 학생과 비공개 묶음의 학생이 혼자 넘기지 않게 하려는 것이다.
   - 테스트용 묶음을 다시 빌드했고, 서버 테스트가 빌드에 `deck:limit`이 없는지도 본다.
6. **다시 보기(T037과 겹치는 부분)**: `limit`이 없어져 다시 보기에서도 범위 끝 문구와 끝으로 당기기를 뺐다.
   - 공개 묶음은 끝까지 넘기고, 보던 곳이 묶음 밖이면 마지막 슬라이드에서 이어 본다.
   - 비공개 묶음의 안내(T033)는 그대로다.
   - T037에는 다시 보기 E2E(비공개는 자료만, 공개하면 끝까지)와 남은 정리가 남는다.
