# 슬라이드 동기화와 교수 메시지·자료 푸시

> 규칙: 이 문서에는 **관찰할 수 있는 동작**만 씁니다. 프레임워크, 테이블, API 경로, 라이브러리 이름은 plan.md에 씁니다.

## 목적

교수가 회차마다 슬라이드를 올려 두고 수업 중 넘기면 프로젝터와 학생 휴대폰이 바로 따라오고, 슬라이드 밖의 프롬프트나 링크를 수업 흐름을 끊지 않고 학생에게 보낸다.

## 용어

- **회차**: 강좌 안의 수업 한 번(예: "3주차 1회차"). 상태는 **예정 → 진행 중 → 종료** 중 하나다. 출석(003)과 채팅(004)도 회차 단위로 쌓인다.
- **슬라이드 묶음**: 교수가 자기 컴퓨터에서 Slidev로 빌드한 결과 폴더를 zip으로 묶은 파일. 회차마다 하나.
- **단계**: 한 슬라이드 안에서 클릭할 때마다 나타나는 부분. 슬라이드 위치는 "몇 번째 슬라이드의 몇 번째 단계"다.
- **공개 묶음 / 비공개 묶음**: 교수가 회차의 슬라이드 묶음마다 고르는 상태. 공개 묶음은 학생이 언제든 처음부터 끝까지 넘겨 볼 수 있다(예습과 복습). 비공개 묶음은 학생이 수업 중에 교수 화면을 따라갈 때만 보인다. 새로 올린 묶음은 비공개다.
- **보낸 항목**: 교수가 수업 중 학생에게 보낸 글(프롬프트)이나 링크.

## 시나리오

### S1. 회차 준비
- **누가·언제**: 교수가 수업 전에 관리 페이지에서.
- **무엇을 제공하나**: 회차 만들기, 이름 바꾸기, 삭제, 회차 선택, 회차별 슬라이드 묶음 올리기·바꾸기·지우기, 묶음의 공개·비공개.
- **완료할 작업**: 이번 수업의 회차를 만들고 슬라이드를 올려 둔다. 미리 보여 줘도 되는 슬라이드는 공개해 학생이 예습하게 한다.

### S2. 수업 시작과 진행
- **누가·언제**: 교수가 강의실에서 노트북으로 수업을 시작할 때.
- **무엇을 제공하나**: 관리 페이지의 '수업 시작', 교수 수업 화면(슬라이드, 이전/다음, 다음 슬라이드, 발표자 노트, 동기화 현황), 프로젝터 화면을 여는 버튼.
- **완료할 작업**: 프로젝터 창을 띄우고 슬라이드를 넘기며 수업한다.

### S3. 학생이 따라 보기와 직접 넘겨 보기
- **누가·언제**: 입장한 학생이 수업 중 휴대폰으로.
- **무엇을 제공하나**: 교수 화면을 따라가는 슬라이드. 공개 묶음이면 이전·다음(누르거나 넘기면 따라가기가 풀린다)과 '교수 화면으로'(다시 따라가기).
- **완료할 작업**: 프로젝터가 잘 안 보여도 손에서 슬라이드를 본다. 공개 묶음이면 지나간 슬라이드나 앞 슬라이드를 직접 넘겨 본다.

### S4. 메시지·자료 보내기
- **누가·언제**: 교수가 수업 중 슬라이드에 없는 프롬프트나 링크를 나눠 줄 때.
- **무엇을 제공하나**: 교수 수업 화면의 '메시지·자료 보내기' 탭, 학생 화면의 '자료' 탭과 도착 알림.
- **완료할 작업**: 학생이 받은 글을 복사하거나 링크를 연다. 잘못 보낸 항목은 거둔다.

### S5. 수업 종료와 다시 보기, 미리 보기
- **누가·언제**: 수업이 끝났을 때, 학생이 나중에 복습할 때, 학생이 수업 전에 예습할 때.
- **무엇을 제공하나**: '수업 종료', 학생 화면의 지난 회차 목록과 미리 볼 수 있는 회차 목록.
- **완료할 작업**: 수업을 닫는다. 학생은 받은 항목과 공개된 슬라이드를 다시 보고, 다음 수업의 공개된 슬라이드를 미리 본다.

### S6. 분반·새 학기 복제 시 회차 복사
- **누가·언제**: 교수가 강좌를 '분반 만들기'나 '새 학기로 복제'로 복제할 때(001 S4).
- **무엇을 제공하나**: 회차 이름과 올린 슬라이드 묶음의 복사.
- **완료할 작업**: 같은 슬라이드로 새 강좌의 수업을 바로 준비한다.

## 수용 기준

### 회차 관리 (관리 페이지)

- [ ] AC1. 관리 페이지 위쪽에 회차 선택이 있고, 회차가 없으면 "아직 회차가 없습니다. 회차를 만들어 수업을 준비하세요."와 **회차 만들기**가 보인다.
- [ ] AC2. 회차 만들기에서 이름(1~40자)을 넣으면 회차가 '예정' 상태로 목록 끝에 생기고 선택된다. 이름이 비어 있으면 만들기 버튼이 흐려진다. 같은 강좌 안에서 이름이 겹쳐도 된다.
- [ ] AC3. 회차 선택 목록에는 각 회차의 이름과 상태(예정/진행 중/종료)가 글로 보인다. 진행 중인 회차는 아이콘과 글로 구분된다(색만으로 구분하지 않는다).
- [ ] AC4. 회차 이름은 언제든 바꿀 수 있다. **삭제**는 한 번도 시작하지 않은 '예정' 회차에만 보이고, 확인 문구 "{회차 이름} 회차를 삭제할까요? 올린 슬라이드도 함께 지워집니다." 뒤에 지워진다.
- [ ] AC5. 선택한 회차의 '이 회차의 자료' 구역에서 슬라이드 묶음(zip)을 올리면 "업로드됨" 배지, 파일 이름, 올린 시각, 슬라이드 수가 보인다. 올리지 않았으면 "비어 있음" 배지가 보인다.
- [ ] AC6. Slidev 빌드 결과가 아닌 zip을 올리면 아무것도 바뀌지 않고 "슬라이드 묶음을 읽을 수 없습니다. Slidev로 빌드한 폴더(dist)를 zip으로 묶어 올려 주세요."가 보인다. 크기 상한(제안 100MB)을 넘으면 "파일이 너무 큽니다. 100MB 이하로 올려 주세요."가 보인다.
- [ ] AC47. '이 회차의 자료' 구역의 슬라이드 묶음 옆에 **학생에게 공개** 스위치가 있다. 새로 올리거나 바꾼 묶음은 꺼진 상태(비공개)다. 스위치 옆에 지금 상태가 글로 보인다: 켜면 "공개 · 학생이 언제든 처음부터 끝까지 볼 수 있습니다.", 끄면 "비공개 · 학생은 수업 중 교수 화면을 따라갈 때만 봅니다.". 공개·비공개는 회차 상태(예정·진행 중·종료)와 관계없이 언제든 바꿀 수 있다.
- [ ] AC7. 예정·종료 회차의 슬라이드 묶음은 바꾸거나 지울 수 있다. 진행 중인 회차에서는 바꾸기와 지우기가 흐려지고 "수업 중에는 슬라이드를 바꿀 수 없습니다."가 보인다.
- [ ] AC8. 강좌 목록의 강좌 카드에 "진행 회차 N"이 보인다. N은 한 번이라도 시작한 회차 수다.

### 수업 시작과 교수 수업 화면

- [ ] AC9. 예정 회차를 선택하면 **수업 시작**이 보인다. 누르면 회차가 '진행 중'이 되고 교수 수업 화면이 열린다. 슬라이드가 없으면 먼저 "슬라이드 없이 시작할까요? 메시지·자료 보내기만 쓸 수 있습니다."를 확인한다.
- [ ] AC10. 한 강좌에서 진행 중인 회차는 하나뿐이다. 다른 회차가 진행 중이면 수업 시작 대신 "{회차 이름} 수업이 진행 중입니다. 먼저 끝내 주세요."와 그 회차로 가는 버튼이 보인다.
- [ ] AC11. 보관된 강좌에서는 수업 시작이 보이지 않고 "보관된 강좌는 수업을 시작할 수 없습니다."가 보인다.
- [ ] AC46. 수업이 진행 중인 강좌는 보관할 수 없다. '보관'을 확인하면 보관하지 않고 "{회차 이름} 수업이 진행 중입니다. 수업을 끝낸 뒤 보관해 주세요."와 그 회차로 가는 버튼이 보인다. 수업과 학생 로그인은 그대로다.
- [ ] AC12. 교수 수업 화면에는 메뉴바가 없고, 위쪽에 강좌·회차 이름, 경과 시간, 접속 학생 수, **프로젝터 화면 열기**, **수업 종료**가 있다.
- [ ] AC13. 왼쪽에 현재 슬라이드(16:9), **이전**·**다음**, 다음 슬라이드 미리보기, 발표자 노트가 보인다. 키보드 →·Space는 다음, ←는 이전이며, 글 입력 칸에 초점이 있을 때는 동작하지 않는다.
- [ ] AC14. 다음은 현재 슬라이드에 남은 단계가 있으면 다음 단계를, 없으면 다음 슬라이드의 첫 단계를 보인다. 처음과 끝에서는 해당 버튼이 흐려진다.
- [ ] AC15. 슬라이드 아래에 "따라가는 중 N명 · 직접 넘겨 보는 중 M명"이 보이고 학생이 들어오거나 전환하면 바뀐다. 누가 어느 쪽인지는 보이지 않는다.
- [ ] AC16. 교수 수업 화면을 닫았다가(또는 새로 고쳐) 다시 열면 같은 회차의 마지막 위치에서 이어진다. 수업은 '수업 종료'를 누르기 전까지 진행 중으로 남는다.
- [ ] AC17. 같은 교수가 교수 수업 화면을 두 개 열어도 둘은 같은 위치를 보이고, 어느 쪽에서 넘겨도 다른 쪽이 따라온다.
- [ ] AC18. 진행 중인 회차는 관리 페이지에서 **수업 화면으로**를 눌러 다시 열 수 있다.

### 프로젝터 화면

- [ ] AC19. '프로젝터 화면 열기'를 누르면 새 창이 열리고 슬라이드만 화면 가득(16:9 맞춤) 보인다. 발표자 노트, 다음 슬라이드, 버튼은 보이지 않는다. 창 안에서 **전체 화면** 버튼이나 F 키로 전체 화면이 된다.
- [ ] AC20. 프로젝터 화면은 교수의 위치(슬라이드와 단계)를 그대로 따라오고 직접 넘길 수 없다.
- [ ] AC21. 슬라이드 왼쪽 위에는 아무것도 얹지 않는다. 연결 상태 표시는 오른쪽 아래 구석에 작게만 나타난다(끊겼을 때만).
- [ ] AC22. 프로젝터 화면은 교수 계정으로만 열린다. 로그인하지 않은 브라우저에서 주소를 열면 교수 로그인 화면으로 간다.

### 학생 수업 화면

- [ ] AC23. 입장한 학생이 강좌 링크를 열면, 진행 중인 회차가 있으면 바로 수업 화면이, 없으면 "지금 진행 중인 수업이 없습니다. 수업이 시작되면 이 화면이 바뀝니다."와 지난 회차 목록이 보인다. 화면을 열어 둔 채 수업이 시작되면 새로 고치지 않아도 수업 화면으로 바뀐다.
- [ ] AC24. 수업 화면은 맨 위에 슬라이드(화면 폭, 16:9), 그 아래 수업 정보 줄(강좌·회차 이름, 내 닉네임), 따라가기 줄(상태 글, 공개 묶음이면 **이전**·**다음**과 따라가지 않을 때 **교수 화면으로**), '자료' 탭 순서다. 390px 폭에서 가로로 넘치지 않는다.
- [ ] AC25. 처음에는 **교수 화면 따라가는 중**이고, 교수가 넘기면 1초 안에 학생 슬라이드도 같은 위치로 바뀐다(학생 200명 기준).
- [ ] AC26. 공개 묶음에서 따라가는 중에 학생이 슬라이드를 넘기면(**이전**·**다음** 누르기, 슬라이드를 옆으로 밀기, 키보드 ←·→) 따라가기가 풀리고 그 방향으로 한 단계 움직인다. 이때부터 교수가 넘겨도 학생 슬라이드는 그대로이고, 따라가기 줄이 "직접 넘겨 보는 중 · 교수 화면은 {N}번 슬라이드입니다."와 **교수 화면으로**로 바뀐다. 슬라이드 안의 링크나 버튼을 누르기, 화면 스크롤, '자료' 탭으로 옮기기는 따라가기를 풀지 않는다. 직접 넘겨 보기에서는 묶음의 처음부터 끝까지 갈 수 있다. 처음과 끝에서는 해당 버튼이 흐려지고, 그 밖으로 넘기려 하면 움직이지 않고 따라가기도 풀리지 않는다.
- [ ] AC27. 비공개 묶음이면 학생은 교수 화면을 따라가기만 한다. **이전**·**다음**과 **교수 화면으로**가 없고, 슬라이드를 밀거나 ←·→를 눌러도 움직이지 않는다. 따라가기 줄에는 "교수 화면 따라가는 중 · 교수님이 슬라이드를 공개하면 직접 넘겨 볼 수 있습니다."가 보인다.
- [ ] AC48. 수업 중에 교수가 공개·비공개를 바꾸면 1초 안에 학생 화면에 반영된다. 공개로 바꾸면 이전·다음이 나타난다. 비공개로 바꾸면 직접 넘겨 보던 학생은 교수의 현재 위치로 돌아가 따라가는 중이 되고, "교수님이 슬라이드를 비공개로 바꿨습니다. 교수 화면을 따라갑니다."가 보인다(화면 낭독기에도 읽힌다).
- [ ] AC28. **교수 화면으로**를 누르면 교수의 현재 위치로 돌아가고 다시 따라가는 중이 된다. 직접 넘기다가 교수와 같은 위치에 닿아도 저절로 다시 따라가지는 않는다(이 버튼을 눌러야 한다).
- [ ] AC29. 수업 중에 들어오거나 새로 고친 학생은 교수의 현재 위치에서 따라가는 중으로 시작하고, 이번 회차에 이미 보낸 항목을 모두 '자료' 탭에서 본다.
- [ ] AC30. 발표자 노트는 학생 화면과 프로젝터 화면 어디에도 나오지 않는다.

### 메시지·자료 보내기

- [ ] AC31. 교수 수업 화면 오른쪽에 **메시지·자료 보내기** 탭이 있다. 글 칸(1~2000자)과 링크 칸(선택)에 넣고 **학생에게 보내기**를 누르면 아래 '보낸 항목' 목록 맨 위에 시각과 함께 추가된다. 글과 링크가 모두 비어 있으면 버튼이 흐려진다.
- [ ] AC32. 링크는 http:// 또는 https://로 시작해야 하며, 아니면 보내지 않고 "링크는 http:// 또는 https://로 시작해야 합니다."가 보인다.
- [ ] AC33. 보낸 항목은 1초 안에 수업 중인 학생의 '자료' 탭 맨 위에 나타나고, 화면 아래에 "교수님이 자료를 보냈습니다."가 몇 초간 보인다(화면 낭독기에도 읽힌다). '자료' 탭에 읽지 않은 수가 보인다.
- [ ] AC34. 학생 '자료' 탭의 글 항목에는 **복사** 버튼이 있고, 누르면 글 전체가 복사되며 "복사했습니다."가 보인다. 링크는 새 탭으로 열린다.
- [ ] AC35. 교수는 보낸 항목마다 **거두기**를 누를 수 있다. 확인 뒤 그 항목은 1초 안에 학생 화면에서 사라지고, 교수 목록에는 "거둔 항목 · 학생에게 보이지 않습니다."로 남는다. 거둔 항목은 되살리지 않는다.
- [ ] AC36. '보낸 항목' 목록 아래에 "보낸 항목은 수업이 끝난 뒤 공개할 목록으로 정리됩니다."가 보인다(공개 자체는 006).

### 수업 종료와 다시 보기

- [ ] AC37. **수업 종료**를 누르면 확인 문구를 보인 뒤 회차가 '종료'가 되고 관리 페이지로 돌아간다. 확인 문구는 공개 묶음이면 "수업을 끝낼까요? 학생은 슬라이드와 받은 자료를 계속 볼 수 있습니다.", 비공개 묶음이거나 묶음이 없으면 "수업을 끝낼까요? 학생은 받은 자료를 계속 볼 수 있습니다. 슬라이드는 공개해야 볼 수 있습니다."다.
- [ ] AC38. 수업이 끝나면 수업 중인 학생 화면은 새로 고치지 않아도 "수업이 끝났습니다."로 바뀌고, 같은 회차의 다시 보기로 이어진다.
- [ ] AC39. 학생의 지난 회차 목록에는 종료된 회차가 최근 것부터 보인다. 회차를 열면 거두지 않은 보낸 항목이 보인다. 공개 묶음이면 슬라이드를 처음부터 끝까지 넘겨 볼 수 있고, 비공개 묶음이면 슬라이드 자리에 "이 회차의 슬라이드는 공개되지 않았습니다."가 보인다.
- [ ] AC40. 종료된 회차는 관리 페이지에서 **이어서 수업하기**로 다시 진행 중으로 만들 수 있다(실수로 끝낸 경우). 이어서 하면 마지막 위치에서 시작하고, 보낸 항목은 그대로 이어진다. 다른 회차가 진행 중이면 AC10과 같다.
- [ ] AC41. 종료된 회차의 슬라이드 묶음을 바꾸면 새 묶음은 비공개로 시작한다(AC47). 교수가 공개하면 학생 다시 보기에 새 묶음 전체가 보인다.
- [ ] AC49. 학생 대기 화면에는 지난 회차 목록 위에 **미리 볼 수 있는 회차**가 있다. 공개 묶음이 있는 '예정' 회차가 회차 순서대로 보이고, 열면 그 슬라이드를 처음부터 끝까지 넘겨 볼 수 있다. 그런 회차가 없으면 이 목록은 보이지 않는다. 미리 보던 회차의 수업이 시작되면 AC23대로 수업 화면으로 바뀐다.
- [ ] AC50. 비공개 묶음의 슬라이드는 수업 중 따라가기 밖에서는 학생에게 내주지 않는다. 학생이 주소를 직접 열어도 볼 수 없다. 묶음을 비공개로 바꾸면 그때부터 내주지 않는다.

### 복제

- [ ] AC42. '분반 만들기'나 '새 학기로 복제'로 만든 강좌에는 원래 강좌의 회차가 같은 이름·순서로 '예정' 상태로 생기고, 올린 슬라이드 묶음도 함께 있다. 복사된 묶음은 비공개다. 보낸 항목, 시작·종료 기록은 복사되지 않는다.

### 권한과 접근성

- [ ] AC43. 회차 관리, 수업 시작·종료, 슬라이드 넘기기, 보내기·거두기, 프로젝터 화면은 그 강좌의 교수만 할 수 있다. 다른 교수나 학생이 시도하면 "이 강좌에 대한 권한이 없습니다."가 보인다.
- [ ] AC44. 학생은 자기가 입장한 강좌의 회차만 볼 수 있다. 명단에서 빠졌거나 로그인이 끊긴 학생(001)은 수업 화면 대신 입장 화면으로 간다.
- [ ] AC45. 이 스펙의 모든 버튼과 입력은 높이 44px 이상이고, 키보드만으로 쓸 수 있으며, 초점 링이 보인다. 이전·다음·복사·거두기처럼 아이콘이 있는 버튼은 화면 낭독기가 읽는 이름이 있다.

## 오류와 예외 동작

- **학생 연결이 끊김**: 슬라이드는 마지막 화면 그대로 남고 위쪽에 "연결이 끊겼습니다. 다시 연결하는 중…"이 보인다. 다시 연결되면 안내가 사라지고, 따라가는 중이었다면 교수의 현재 위치로 바로 가며, 끊긴 동안 보낸 항목이 '자료' 탭에 모두 나타난다(놓친 항목 0개, C12). 거둔 항목은 사라진다.
- **교수 연결이 끊김**: 교수 수업 화면에 "연결이 끊겼습니다. 다시 연결하는 중…"이 보이고, 이전·다음과 보내기가 흐려진다(눌렀는데 반영되지 않은 척하지 않는다). 학생과 프로젝터는 마지막 위치에 머문다. 다시 연결되면 저장된 위치에서 이어진다.
- **프로젝터 연결이 끊김**: 슬라이드는 그대로 두고 오른쪽 아래에 작은 끊김 표시만 보인다. 다시 연결되면 교수의 현재 위치로 간다. 프로젝터 창을 닫아도 교수 수업 화면에서 다시 열 수 있다.
- **서버를 다시 시작함**: 진행 중인 회차, 현재 위치, 묶음의 공개 여부, 보낸 항목과 거둔 상태는 남는다(C13). 연결된 화면은 위의 "다시 연결" 동작을 따른다.
- **보내기 실패**: 저장되지 않은 항목은 목록에 추가되지 않고 글이 칸에 남은 채 "보내지 못했습니다. 연결을 확인하고 다시 보내 주세요."가 보인다. 한 번 누른 보내기는 두 번 저장되지 않는다.
- **슬라이드 묶음이 열리지 않음**(수업 중 파일 문제 등): 교수 수업 화면은 슬라이드 자리에 "슬라이드를 열 수 없습니다. 메시지·자료 보내기는 계속 쓸 수 있습니다."를 보인다. 교수는 자기 노트북의 원본으로 발표를 이어가고, 보내기로 자료를 나눠 줄 수 있다(대체 경로, C12).
- **올리기 실패**: 파일이 끝까지 올라가지 않으면 이전 슬라이드 묶음이 그대로 남고 "올리지 못했습니다. 다시 올려 주세요."가 보인다. 반쯤 올라간 묶음은 쓰이지 않는다.
- **학생 휴대폰이 느림**: 슬라이드를 아직 받는 중이면 슬라이드 자리에 "슬라이드를 불러오는 중…"이 보이고, 받는 동안에도 '자료' 탭은 쓸 수 있다.

## constitution 영향

- C2: 보낸 항목은 교수가 입력한 데이터라 006에서 공개 후보가 될 수 있다. 학생별 따라가기 상태와 접속 기록은 공개 대상이 아니다.
- C5: 회차, 슬라이드 묶음, 위치, 보낸 항목은 모두 강좌 단위로 구분한다. 다른 강좌의 회차는 보이지 않는다. AC44.
- C6: 수업 시작·종료·이어서 하기, 보내기·거두기, 묶음 공개·비공개는 수정할 수 없는 기록으로 쌓는다. 거둔 항목도 원문은 기록에 남고 학생에게만 숨긴다. AC35.
- C7: 동기화 현황은 숫자만 보인다. 누가 따라가는지는 화면과 기록에 학생 이름·이메일로 남기지 않는다. AC15.
- C8: 교수 전용 동작과 학생 열람 범위(공개 묶음, 수업 중 따라가기)는 한 곳의 권한 판단을 거친다. AC43, AC44, AC50.
- C12: 연결이 끊겨도 슬라이드가 멈출 뿐 수업은 계속되고, 다시 연결되면 위치와 놓친 항목을 되찾는다. 슬라이드가 열리지 않아도 보내기로 수업을 이어 간다.
