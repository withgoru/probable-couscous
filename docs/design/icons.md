# 사용한 아이콘 (Iconoir regular)

`npm install iconoir` 의 `icons/regular/<이름>.svg`를 쓴다. 선 두께 1.5, 색은 `currentColor`.

| `calendar-check` | Components, Courses |
| `chat-bubble` | Components, ProfessorSplit, Projector, Student |
| `check` | Components, Settings, Student |
| `clock` | Components, Main |
| `copy` | Components, Student |
| `eye` | Admin, Components |
| `eye-closed` | Components, Main, ProfessorSplit, Student |
| `git-branch` | Components, Settings |
| `github` | Components, Login, MyPage, Settings |

| `info-circle` | Admin, Components |
| `key` | Admin, Components, Student |

| `lock` | Components, Main, ProfessorSplit, Student |
| `log-out` | Components |
| `mail` | Components, Student |
| `nav-arrow-down` | Admin, Components, Settings |
| `nav-arrow-left` | Components, Main, ProfessorSplit, Student |
| `nav-arrow-right` | Components, Main, ProfessorSplit, Student |
| `page` | Admin, Components, Student |
