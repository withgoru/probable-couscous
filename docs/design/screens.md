# 화면 설명

목업 원본은 `mockups/` 아래 같은 이름의 파일입니다. 이 문서는 각 화면의 **구성, 상태, 동작, 핵심 문구**를 정리한 것으로, 스펙을 쓸 때 "관찰할 수 있는 동작"의 재료로 씁니다. 목업은 참고 자료이며 스펙이 우선합니다. 목업의 이름·학번·채팅은 모두 샘플입니다.

## 화면 흐름

```
Login ─▶ Courses ─▶ Admin(강좌별 관리 페이지)
            │            └─ 수업 시작 ─▶ Main(교수 수업 화면) + Projector + ProfessorSplit
            ├─ 계정 드롭다운 ─▶ MyPage / Settings / 로그아웃(Login)
학생: 초대 링크 ─▶ Student (이메일 ─▶ 인증 코드 ─▶ 채팅 이용 안내 ─▶ 출석코드 ─▶ 수업 중)
```

로그인 후 화면(Courses, MyPage, Settings, Admin)에는 공통 메뉴바가 있고 오른쪽에 계정 드롭다운(@GitHub 계정, 마이페이지, 설정, 로그아웃)이 항상 있습니다. 수업 중 화면에는 메뉴바가 없습니다.

## Login — 교수 로그인
- 가운데 카드: "교수 로그인", 설명, **GitHub로 로그인** 버튼(전체 폭, 큰 크기), 아래에 "학생이신가요? 가입 없이, 교수님이 보낸 초대 링크를 열어 이메일로 입장합니다."
- 상태: 허용 목록에 없는 계정이면 오류 알림 "이 GitHub 계정은 사용할 수 없습니다 / 허용 목록에 없는 계정입니다. 허용된 계정으로 다시 로그인해 주세요."
- 이동: 로그인 성공 → Courses.

## Courses — 내 강좌 (로그인 후 첫 화면)
- 제목 "내 강좌", 오른쪽 **새 강좌 만들기**.
- 새 강좌 만들기: 카드 폼(강좌 이름, 분반 이름 선택), 만들기(이름이 비어 있으면 흐리게), 취소. 만들면 진행 중 목록 맨 앞에 추가된다.
- 밑줄 탭 **진행 중 N / 보관됨 N**.
- 강좌 카드: 이름, "분반 · 학기", 배지(진행 중=성공색, 보관됨=보조색), 수강생 N명, 진행 회차. 버튼: **열기**(진행 중) / **기록 보기**(보관됨), **분반 만들기** / **새 학기로 복제**.
- 분반은 별도 개념이 아니라 강좌를 복제해서 만든다(자료 복사, 수강생·기록은 새로 시작).

## MyPage — 마이페이지
- 프로필 카드(아바타, @GitHub 계정, "GitHub 계정으로 로그인됨"), 통계 카드 3개(진행 중 강좌, 보관된 강좌, 진행 중 수강생 합계), 진행 중 강좌 목록과 **열기**.

## Settings — 설정
- 카드 3개: **계정**(GitHub 정보, 설명 "이 계정으로만 강좌를 만들고 관리할 수 있습니다. 로그인 정보는 이메일 주소와 프로필만 읽습니다."), **새 강좌 기본값**(출석코드 표시 시간 5/10/15분 기본 10분, 채팅 시작 모드 자유/읽기 전용, 저장 → "저장했습니다"), **수업 자료 공개 저장소**(이후 단계 배지, "연결된 저장소 없음", 저장소 연결).
- 로그아웃 버튼은 여기에 두지 않는다(계정 드롭다운에만).

## Admin — 교수 관리 페이지 (강좌 하나)
- 제목 "관리 페이지", 오른쪽에 회차 선택.
- 왼쪽: **이 회차의 자료**(슬라이드 Slidev 빌드 zip, 슬라이드 PDF, 보충 자료, 자료 추가, 업로드됨/비어 있음 배지), **출석 현황**(표: 학번, 이름, 출석 시각, 상태. 보정 요청이 있으면 **보정 승인** 버튼, 승인하면 "출석 (수기 보정)", 상단 "출석 N / 42").
- 오른쪽: **작성자 확인**(1. 대상 글 선택 2. 사유를 목록에서 선택 — 협박·위해 예고 / 심한 괴롭힘·혐오 표현 / 자해·위기 신호 / 불법 정보 / 부정행위, 안내 "단순한 욕설, 수업 방해, 교수에 대한 비판은 사유 목록에 없습니다.", 버튼 "작성자 확인 (기록됩니다)"은 대상과 사유가 모두 있어야 활성, 결과는 학번·이름 알림), **조회 기록**(시각, 사유, 대상 글, 조회자. 없으면 "이 강의실에서 작성자를 확인한 기록이 없습니다.").
- 안내문: "심각한 사안에 한해 사용합니다. 모든 조회는 사유와 함께 기록되며 지울 수 없습니다. 채팅 내용은 참여 점수에 반영되지 않습니다."

## Main — 교수 수업 화면 (통합 보기, 노트북 + 프로젝터)
- **상단**: 강좌·회차 제목, 경과 시간, 접속 38/42, 출석 36, **출석코드 박스**(6자리, 15초마다 갱신, 진행 막대, "N초 후 갱신 · 표시 종료 2:53"), **채팅 읽기 전용 스위치**, **수업 종료**(위험 테두리 버튼).
- **왼쪽**: 슬라이드 미리보기(어두운 면, 16:9), **이전/다음**, 동기화 상태("따라가는 중 34명 · 직접 넘겨 보는 중 4명"), 다음 슬라이드 카드, 발표자 노트 카드.
- **오른쪽 카드**: 밑줄 탭 **채팅 N / 메시지·자료 보내기**.
  - 채팅: 모드 줄(자유 모드=정보색, 읽기 전용=경고색), 메시지 행(아바타 이니셜, 닉네임, 시각, 글, **숨김** 아이콘 버튼). 숨기면 "숨김 처리됨 · 닉네임 / 학생에게 보이지 않습니다. 원문은 보존됩니다." + **복원**. 하단 안내 "학생에게는 닉네임으로만 보입니다. 이 화면에도 실명은 표시되지 않으며, 신원 조회는 관리 페이지에서만 가능합니다."
  - 메시지·자료 보내기: 텍스트 영역, 파일·링크 첨부, **학생에게 보내기**, 보낸 항목 목록, "보낸 항목은 수업이 끝난 뒤 공개할 목록으로 정리됩니다."

## ProfessorSplit — 교수 보조 화면 (태블릿 1024×700)
장비가 다양해도 쓸 수 있도록 같은 기능을 패널로 나눈 화면입니다.
- 상단: "노트북과 연결됨" 배지, 채팅 모드 배지.
- 왼쪽: 채팅 목록(숨김/복원).
- 오른쪽 카드 4개: 출석 36/42 + **수기 보정 요청**(학번 · 사유, 승인), **슬라이드 원격 조작**(이전/다음, 현재 슬라이드), **채팅 읽기 전용** 스위치, **학생에게 메시지 보내기**.

## Projector — 프로젝터 화면 (1280×720, 학생 전체가 보는 화면)
- 슬라이드(어두운 면) + **오른쪽 사이드바 400px**: 위에 **출석코드 카드**(원형 카운트다운, 6자리, "15초마다 바뀝니다"), 아래에 **채팅**(헤더의 **표시** 스위치), 메시지 목록(학생=흰 말풍선, 교수=정보색 연한 파랑 말풍선과 "교수" 이름), 하단 "닉네임으로만 표시됩니다. 교수님이 숨긴 글은 나오지 않습니다."
- **채팅 끄기**: 사이드바가 사라지고 슬라이드가 전체 폭이 되며, 출석코드는 오른쪽 위 카드로 남고, 오른쪽 아래에 "채팅 표시" 스위치.
- **출석코드 표시 끄기**(수업 시작 후 설정 시간이 지났을 때): 코드 카드가 사라진다.
- 슬라이드 왼쪽 위에는 아무것도 얹지 않는다(슬라이드에 중요한 정보가 있다).
- 이 화면에서 출석코드를 뺀 구성이 학생이 수업 중 보는 화면과 같다.

## Student — 학생 모바일 화면 (390×844)
단계: **이메일 → 인증 코드 → 채팅 이용 안내 → 출석코드 → 수업 중**
1. **이메일**: 초대 링크로 들어옴, "수강생 명단에 있는 이메일로 입장합니다. 가입은 필요 없습니다." 이메일 입력(형식 오류 시 "이메일 형식을 확인해 주세요."), **인증 코드 받기**.
2. **인증 코드**: 6자리 입력(72px), "이 기기에서 로그인 유지" 체크(기본 켜짐), **확인하고 계속**, 도움 카드("메일이 오지 않나요?", 코드 다시 받기, 이메일 다시 입력).
3. **채팅 이용 안내**: 닉네임 카드(자동 부여), 안내 3줄(닉네임으로만 보임 / 교수는 심각한 사안에 한해 사유를 기록하고 확인 가능 / 점수에 반영되지 않고 공개되지 않음), **확인하고 입장**.
4. **출석코드**: "교실 화면 오른쪽 위의 숫자 6자리입니다. 15초마다 바뀌니 보이는 숫자를 바로 입력하세요." 6자리 입력, **출석하기**, 도움 카드 **수기 출석 요청 보내기**(누르면 "요청을 보냈습니다. 교수님이 확인하면 출석 처리됩니다.").
5. **수업 중**(유튜브 구조): 맨 위 슬라이드(16:9, 화면 폭), 수업 정보 줄(강좌·회차, 닉네임, "출석 완료" 배지), 따라가기 줄(**교수 화면 따라가는 중** + **직접 넘겨 보기** → 이전/다음/교수 화면으로), 밑줄 탭 **채팅 / 자료**.
   - 채팅: 말풍선(다른 학생=연한 회색, 나=primary 색 오른쪽, 교수=정보색 연한 파랑 + 파란 이름), 입력 줄 + 보내기. 읽기 전용이면 상단 경고 "교수님이 채팅을 읽기 전용으로 바꿨습니다. 새 글은 쓸 수 없습니다."와 입력 비활성.
   - 자료: 교수가 보낸 프롬프트(시각, **프롬프트 복사**), 슬라이드 PDF 안내("수업이 끝난 뒤 교수님이 올리면 여기서 받을 수 있습니다.").

## Components — 디자인 시스템 시트
색 토큰, 글자, 아이콘 34종, 버튼, 입력, 탭·배지·알림, 카드·표·메뉴·대화상자, 서비스 전용 구성(출석코드 카드, 채팅 메시지 3종, 슬라이드 미리보기)을 한 화면에 모은 것. 토큰과 규칙은 `tokens.md`.
